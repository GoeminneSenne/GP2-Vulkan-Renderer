This project is a custom Vulkan framework, created for the Graphics Programming 2 course of the DAE curriculum. It reduces the complexity and abstraction of setting up a Vulkan Application. it offers structured rendering architecture and the ability to import OBJ files and complete GLTF scenes.

Planned Features:
* Modern Vulkan Features
* Deferred Rendering Pipeline + Depth Prepass
* Physical Based Lighting using Cook Torrance BRDF materials
* Image Based Lighting
* Tone Mapping
* Shadow Mapping
